THE COMFORT HEAVEN SOHELA — SINGLE-FILE GITHUB PAGES WEBSITE

FIX FOR MISSING PHOTOS
This version embeds the shop and product photos directly inside index.html. Upload ONLY index.html to the root of your GitHub Pages repository; no assets folder is needed.

PUBLISH
1. Download and extract this ZIP.
2. Open your GitHub repository (the one that currently shows nipundalbehera4-arch.github.io).
3. Replace the existing index.html with this new index.html. On GitHub use Add file > Upload files, select index.html, then commit the change.
4. Wait 1–5 minutes and refresh the site. If the browser cached the old version, refresh again or open the URL in a private tab.

The WhatsApp booking and product enquiry links are retained.
